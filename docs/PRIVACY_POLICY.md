# 개인정보 처리방침

**시행일: 2026년 8월 30일**

Tori Wallet(이하 "앱")은 사용자의 개인정보를 중요시하며, 개인정보보호법 등 관련 법령을 준수합니다.

## 1. 수집하는 개인정보

### 앱이 자동으로 수집하지 않는 정보

- 현재 광고, 사용자 분석, 원격 충돌 보고, 성능 모니터링 SDK를 연동하지 않았습니다.
- 앱은 기기 모델, 충돌 로그, 성능 데이터를 앱 운영자에게 자동 전송하지 않습니다. 개발·운영 로그는 기기 또는 개발 콘솔에만 기록됩니다.

### 사용자가 기능을 실행할 때 외부로 전달되는 정보

- **문의 이메일**: 사용자가 문의하기를 선택하면 앱 버전과 운영체제 종류가 이메일 초안에 포함됩니다. 사용자가 직접 전송한 경우에만 메일 수신자에게 전달됩니다.
- **블록체인 기능**: 잔액 조회, 거래 조회, 전송 시 지갑 주소와 요청 데이터가 RPC·블록 탐색기 API 또는 퍼블릭 블록체인에 전달될 수 있습니다.
- **WalletConnect**: dApp 연결 시 지갑 주소, 승인한 체인·메서드와 세션 메타데이터가 Reown 네트워크와 해당 dApp에 전달됩니다.
- **스왑·시세 조회**: 토큰, 수량, taker 주소 등 요청 정보가 0x 또는 운영 프록시에 전달될 수 있습니다. 시세 조회는 CoinGecko와 장애 시 CoinCap을 사용합니다.

### 기기에 저장되는 정보

- 니모닉은 PIN으로 암호화해 EncryptedStorage에 저장합니다. 사용자가 생체인증을 활성화한 경우에만 기기 전용 Keychain/Keystore 보호 사본을 추가합니다.
- 개인키를 별도 영구 저장하지 않습니다. 잠금 해제된 세션에서 니모닉으로 파생해 서명에 사용하고, 잠금 또는 백그라운드 전환 시 세션에서 제거합니다.
- 공개 지갑 주소, 앱 설정, 주소록, 거래 캐시, WalletConnect 기록 등은 AsyncStorage와 Realm에 로컬 저장될 수 있습니다.

## 2. 개인정보의 이용 목적

- 앱 기능 제공
- 로컬 오류 분석 및 서비스 안정성 향상
- 사용자 문의 대응

## 3. 개인정보의 보관 및 파기

- **앱 내 초기화**: 설정의 "지갑 초기화"는 WalletConnect 세션 연결 해제, 암호화 지갑 저장소, Realm 기록과 영구 상태 삭제를 시도하며 실패 시 오류를 표시합니다.
- **앱 삭제**: 일반 앱 데이터는 운영체제 정책에 따라 삭제되지만 iOS Keychain 데이터는 앱 삭제 후에도 남을 수 있습니다. 완전한 삭제가 필요한 경우 앱을 삭제하기 전에 "지갑 초기화"를 실행하세요.
- 외부 서비스에 전달된 요청과 온체인 거래는 각 서비스의 정책 및 블록체인 특성상 앱에서 삭제할 수 없습니다.

## 4. 개인정보의 제3자 제공

앱 운영자는 사용자 데이터를 판매하지 않으며 별도 계정 서버에 저장하지 않습니다. 다만 사용자가 기능을 실행하면 서비스 제공에 필요한 정보가 다음 외부 서비스로 전달될 수 있습니다:

- 퍼블릭 블록체인, RPC와 블록 탐색기 API
- Reown WalletConnect 릴레이와 사용자가 연결한 dApp
- 0x Swap API 또는 운영 환경의 스왑 프록시
- CoinGecko와 CoinCap
- 사용자가 선택한 이메일 서비스

## 5. 제3자 서비스

외부 서비스는 요청 과정에서 IP 주소 등 네트워크 메타데이터를 처리할 수 있으며 각 서비스의 개인정보 처리방침이 적용됩니다. Ethereum, Polygon, Arbitrum, Optimism, Base 등 퍼블릭 블록체인에 기록된 거래는 공개되며 되돌리거나 삭제할 수 없습니다.

## 6. 사용자의 권리

사용자는 다음과 같은 권리를 가집니다:

- **로컬 데이터 삭제**: 앱 내 "지갑 초기화" 기능 사용
- **데이터 확인**: 지갑 주소, 주소록, 거래 내역, 연결 세션과 주요 설정을 앱 화면에서 확인
- **문의**: 아래 이메일로 개인정보 관련 문의

## 7. 보안

- 니모닉은 PIN 기반 암호화 볼트에 저장하며, 생체인증 사본은 사용자가 활성화한 경우에만 기기 전용 Keychain/Keystore 정책을 적용
- 개인키는 별도 영구 저장하지 않고 잠금 해제 세션에서 파생
- PIN 및 생체인증을 통한 앱 접근 제어
- 외부 서비스 통신은 HTTPS 또는 WSS 기반 암호화 채널 사용
